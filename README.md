# Hey there, I'm Yago!

I build AI-powered SaaS products, backend systems, and automation workflows that turn messy documents, business rules, and operational data into useful software.

I'm an AI Engineer and Python Developer with 4+ years building backend systems and, since 2023, production AI platforms with LLMs, RAG, OCR, agents, and retrieval workflows. My work is focused on practical AI: systems that connect to real data, call tools, validate outputs, track cost and latency, and create measurable business impact.

Recently, I've been building AI-native products for customs compliance, legal automation, WhatsApp assistants, and agentic analytics. I enjoy working end to end: from architecture and data modeling to backend APIs, retrieval pipelines, evaluation, observability, and deployment.

---

## What I Build

- Production LLM applications with structured outputs, tool calling, retries, evals, and observability
- RAG systems over documents, regulatory references, client files, and business knowledge bases
- OCR + AI workflows for document extraction, validation, and classification
- Agentic workflows that combine SQL, semantic retrieval, APIs, and business logic
- Python backends, APIs, automation pipelines, and reusable internal libraries
